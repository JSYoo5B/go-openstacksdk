# Schema Records

This guide describes the public Go APIs and their contracts against the pinned Gophercloud and Python openstacksdk sources. Support decisions apply to each operation below.

See the [support ledger](../docs/sdk-support-ledger.md) for status definitions and shared limitations.

Python/Go differences:

- The pinned public get_tasks_schema() creates a bare Schema and fetches one fixed discovery document without public inputs. GetSchemaRecord with SchemaTasks is the source-shaped owned mapping; existing GetTasksSchema remains the compatible strict typed alternative with its original actual200 policy and five preserved contracts.
- Resource exposes only the declared class fields under canonical names, including inherited untyped id/name and nullable defaults. Wire is the actual root object; Envelope/Header/StatusCode are additive independent HTTP evidence. self, location from the response, links/templates/$ref/unknown keywords remain passive Wire data; no envelope unwrapping, schema enforcement or follow-up HTTP is inferred.
- Nonnull response dict/list/bool descriptors are projected without narrowing arbitrary JSON items to native string maps/lists. Go retains exact JSON-number spelling and its common bool conversion tests exact decimal zero, so 1e-400 is true instead of false when a Python JSON backend would underflow to binary zero. requests encoding/nonfinite-number behavior is not reproduced; valid UTF8/JSON is the Go lossless domain and invalidUTF8 remains an error.
- The Record profile follows Source HTTP<400/JSON-ValueError tolerance within ordinary final200..399 responses, but parsed nonobject roots remain errors. Success returns an owned record; physical/model/source/context failures return nil record with actual receipt in the error chain. Python exception class spelling, silently ignored physical Close behavior and nonstandard JSON parser corners are deliberate Go error-policy differences.
- Connection current location is captured once for the newly created schema resource; the response has no declared project/zone fields. Python current_location uses zone=None. Go additionally preserves explicit WithCloudLocation or dependency Zone overrides; direct image.New(client) has null location and NewWithDependencies can provide known current facts without application builders.
- Concrete ordinary header options, protected representation/auth/routing policy, immutable captured targets and source checks reuse existing SDK transport. Supplied Resource/subclass, arbitrary URI/query/body, mutable Resource/session/cache and operations on resources are independent original whole-SDK surfaces, not required public inputs or blanket remaining blockers for this finite no-argument getter.

Python/Go differences:

- The pinned public get_metadef_tags_schema() creates a bare MetadefSchema and fetches one fixed discovery document without public inputs. GetSchemaRecord with SchemaMetadefTags is the source-shaped owned mapping; existing GetMetadefTagsSchema remains the compatible strict typed alternative with its original actual200 policy and five preserved contracts.
- Resource exposes only the declared class fields under canonical names, including inherited untyped id/name and nullable defaults. Wire is the actual root object; Envelope/Header/StatusCode are additive independent HTTP evidence. self, location from the response, links/templates/$ref/unknown keywords remain passive Wire data; no envelope unwrapping, schema enforcement or follow-up HTTP is inferred.
- Nonnull response dict/list/bool descriptors are projected without narrowing arbitrary JSON items to native string maps/lists. Go retains exact JSON-number spelling and its common bool conversion tests exact decimal zero, so 1e-400 is true instead of false when a Python JSON backend would underflow to binary zero. requests encoding/nonfinite-number behavior is not reproduced; valid UTF8/JSON is the Go lossless domain and invalidUTF8 remains an error.
- The Record profile follows Source HTTP<400/JSON-ValueError tolerance within ordinary final200..399 responses, but parsed nonobject roots remain errors. Success returns an owned record; physical/model/source/context failures return nil record with actual receipt in the error chain. Python exception class spelling, silently ignored physical Close behavior and nonstandard JSON parser corners are deliberate Go error-policy differences.
- Connection current location is captured once for the newly created schema resource; the response has no declared project/zone fields. Python current_location uses zone=None. Go additionally preserves explicit WithCloudLocation or dependency Zone overrides; direct image.New(client) has null location and NewWithDependencies can provide known current facts without application builders.
- Concrete ordinary header options, protected representation/auth/routing policy, immutable captured targets and source checks reuse existing SDK transport. Supplied Resource/subclass, arbitrary URI/query/body, mutable Resource/session/cache and operations on resources are independent original whole-SDK surfaces, not required public inputs or blanket remaining blockers for this finite no-argument getter.

## Usage examples

Examples use the surrounding guide's service object and context unless they declare a complete program. Python examples describe the pinned comparison API.

```python
import openstack

conn = openstack.connect(cloud="dev")
namespace_schema = conn.image.get_metadef_namespace_schema()
task_schema = conn.image.get_task_schema()
print(namespace_schema.to_dict())
print(task_schema.to_dict())
```

```go
package main

import (
    "context"
    "encoding/json"
    "errors"
    "flag"
    "fmt"
    "log"
    "time"

    sdk "github.com/JSYoo5B/go-openstacksdk"
    "github.com/JSYoo5B/go-openstacksdk/image"
    "github.com/JSYoo5B/go-openstacksdk/resource"
    "github.com/gophercloud/gophercloud/v2"
)

func main() {
    cloudName := flag.String("cloud", "dev", "clouds.yaml cloud name")
    flag.Parse()
    ctx, cancel := context.WithTimeout(context.Background(), time.Minute)
    defer cancel()
    if err := run(ctx, *cloudName); err != nil {
        log.Fatal(err)
    }
}

func printRecord(record *image.SchemaRecord) error {
    if record == nil { return nil }
    data, err := json.MarshalIndent(map[string]any{
        "kind": record.Kind, "resource": record.Resource, "wire": record.Wire,
        "envelope": string(record.Envelope),
        "header": record.Header, "status_code": record.StatusCode,
    }, "", "  ")
    if err != nil { return err }
    fmt.Println(string(data))
    return nil
}

func printFailure(err error) error {
    var data map[string]any
    var accepted *resource.ResponseError
    var unexpected gophercloud.ErrUnexpectedResponseCode
    switch {
    case errors.As(err, &accepted):
        data = map[string]any{
            "status_code": accepted.StatusCode, "header": accepted.Header,
            "body": string(accepted.Body),
        }
    case errors.As(err, &unexpected):
        data = map[string]any{
            "status_code": unexpected.Actual, "header": unexpected.ResponseHeader,
            "body": string(unexpected.Body),
        }
    default:
        return nil
    }
    raw, printErr := json.MarshalIndent(data, "", "  ")
    if printErr != nil { return printErr }
    fmt.Println(string(raw))
    return nil
}

func run(ctx context.Context, cloudName string) error {
    conn, err := sdk.Connect(ctx, sdk.WithCloud(cloudName))
    if err != nil { return err }
    service, err := conn.Image(ctx)
    if err != nil { return err }
    options := []image.GetSchemaOption{
        image.WithGetSchemaHeader("X-Request-Source", "schema-record-example"),
    }
    for _, kind := range []image.SchemaKind{image.SchemaMetadefNamespace, image.SchemaTask} {
        record, readErr := service.GetSchemaRecord(ctx, kind, options...)
        if printErr := printRecord(record); printErr != nil {
            return errors.Join(readErr, printErr)
        }
        if readErr != nil { return errors.Join(readErr, printFailure(readErr)) }
    }
    return nil
}
```
