# Image Record Properties

Python openstacksdk mappings, contracts and differences for these operations are recorded in the review ledger, `api/sdk_reviews.json`.

## Usage examples

```python
import openstack

conn = openstack.connect(cloud="dev")
record = conn.image.get_image("image-id")
updated = conn.image.update_image_properties(
    record,
    team="platform",
    min_ram="512",
    meta={"example_enabled": False},
)
print(updated)
```

See `Example_imageRecordProperties` in [example_image_record_properties_test.go](example_image_record_properties_test.go), compiled by `go test`.
