# Schemas

This guide describes the public Go APIs and their contracts against the pinned Gophercloud and Python openstacksdk sources. Support decisions apply to each operation below.

See the [support ledger](../docs/sdk-support-ledger.md) for status definitions and shared limitations.

## Operation contracts

Python/Go differences:

- Pinned Python openstack.image.v2.schema.Schema uses mutable inherited Resource fetch/descriptor/default/dirty/cache/adapter/session behavior with requires_id=False. Go exposes the fixed singleton method GetImagesSchema, concrete ordinary headers and a passive owned Schema response; complete Resource/cache/exception lifecycle remains broader.
- Pinned ordinary image.v2.schema.Schema declares additional_properties as a dict descriptor and properties as a dict descriptor. Definitions and required descriptors, and bool conversion for additionalProperties, belong to the different MetadefSchema class; these four named getters use ordinary Schema. Go exposes additionalProperties as independent arbitrary raw JSON and optionally projects Definitions/Required through explicit canonical shapes while retaining the actual Body, rather than reproducing Python descriptor coercion or fabricating absent values.
- Go intentionally does not alias-unmarshal embedded Metadata links/timestamps; all schema links/templates/date/identity/URL/dialect values remain raw Body data. Root schema document validation is limited to UTF8/object/canonical field shapes, not JSON Schema draft validity or recursive enforcement.
- Server raw/minimal/CollectionSchema/DictCollectionSchema represent different payloads. Custom image properties/required and optional truthy definitions/links change server documents; the client does not synthesize absent fields, flatten nested item/dictionary schemas or automatically enforce the discovered policies.
- This public schema getter has no ID, supplied Resource, query or request body argument. Proxy._get internally creates a bare Schema with requires_id=False at the declared fixed path. Go adds concrete ordinary-header replacement/merge helpers and returns a new independently owned Schema value; arbitrary supplied subclasses, mutable cached Resource identity and generic fetch/session/cache controls are separate surfaces rather than caller inputs of this named method.
- Go requires original actual HTTP200, canonical UTF-8/non-null JSON-object and declared typed-field shapes, and returns actual Body/Header/StatusCode evidence on accepted processing errors. It preserves configured native prebody retry/reauth/transport behavior and captures route/header policy instead of reproducing all Python Adapter response translation, cached304 and exception/coercion policies. Local fixture/compile checks are evidence for this client mapping, not authenticated deployment or server schema-validation policy.
- Plural schema getters still return one discovery document, with embedded URL/$ref/templates, unknown fields, identity and dates kept passive. Following those values, listing resources, CRUD, Name resolution, recursive JSONSchema validation, schema-driven permission/quota gates, wait or cleanup are outside this named getter and are not synthesized by the Go result. Completing this row does not promote inherited Resource/session or any other image/metadata getter declaration.

```go
package example

import (
    "context"

    "github.com/JSYoo5B/go-openstacksdk/image"
)

func getAllSchemas(ctx context.Context, service *image.Service) (map[string]*image.Schema, error) {
    options := []image.GetSchemaOption{
        image.WithGetSchemaOpts(image.GetSchemaOpts{
            Headers: map[string]string{"X-Request-Source": "example"},
        }),
        image.WithGetSchemaHeader("X-Schema-Request", "discovery"),
        image.WithGetSchemaHeaders(map[string]string{"X-Client-Workflow": "schemas"}),
    }
    getters := []struct {
        path string
        get  func(context.Context, ...image.GetSchemaOption) (*image.Schema, error)
    }{
        {"schemas/images", service.GetImagesSchema},
        {"schemas/image", service.GetImageSchema},
        {"schemas/members", service.GetMembersSchema},
        {"schemas/member", service.GetMemberSchema},
        {"schemas/tasks", service.GetTasksSchema},
        {"schemas/task", service.GetTaskSchema},
        {"schemas/metadefs/namespace", service.GetMetadefNamespaceSchema},
        {"schemas/metadefs/namespaces", service.GetMetadefNamespacesSchema},
        {"schemas/metadefs/resource_type", service.GetMetadefResourceTypeSchema},
        {"schemas/metadefs/resource_types", service.GetMetadefResourceTypesSchema},
        {"schemas/metadefs/object", service.GetMetadefObjectSchema},
        {"schemas/metadefs/objects", service.GetMetadefObjectsSchema},
        {"schemas/metadefs/property", service.GetMetadefPropertySchema},
        {"schemas/metadefs/properties", service.GetMetadefPropertiesSchema},
        {"schemas/metadefs/tag", service.GetMetadefTagSchema},
        {"schemas/metadefs/tags", service.GetMetadefTagsSchema},
    }
    results := make(map[string]*image.Schema, len(getters))
    for _, getter := range getters {
        schema, err := getter.get(ctx, options...)
        if err != nil {
            return results, err
        }
        results[getter.path] = schema
    }
    return results, nil
}
```
