# Image Record Actions

Python openstacksdk mappings, contracts and differences for these operations are recorded in the review ledger, `api/sdk_reviews.json`.

## Usage examples

```python
import openstack

conn = openstack.connect(cloud="dev")
conn.image.deactivate_image("image-id")

# conn.image.reactivate_image("image-id")
```

See `Example_imageRecordActions` in [example_image_record_actions_test.go](example_image_record_actions_test.go), compiled by `go test`.
