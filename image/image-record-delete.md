# Image Record Delete

Python openstacksdk mappings, contracts and differences for these operations are recorded in the review ledger, `api/sdk_reviews.json`.

## Usage examples

```python
import openstack

conn = openstack.connect(cloud="dev")
conn.image.delete_image("image-id", ignore_missing=False)

admin = openstack.connect(cloud="admin")
admin.image.delete_image("other-image-id", store="store-id", ignore_missing=False)
```

See `Example_imageRecordDelete` in [example_image_record_delete_test.go](example_image_record_delete_test.go), compiled by `go test`.
