- Only the two direct BlockStorageCloudMixin declarations search_volumes and get_volume are proposed here, pinned to openstacksdk ef55d7d1666099f50bf1e1c40b59d7e7b72a51fe and native Gophercloud v2.15.0. JSON response id/name preserve untyped values and are stringified with Python-style null/bool/ordered-container representation. Identifier floating spellings use Go shortest float64 rendering at Python cutoffs, including overflow inf and underflow signed zero; exact CPython float repr and Unicode printability database behavior are explicit representation boundaries.
- The source mutable Volume Resource/Munch and class descriptors are represented by an owned normalized 38-key JSON view plus independent original RawResource wire evidence. The view covers the 34 direct v3 Body members, inherited id/name/metadata and computed location used by these helpers, without implementing mutable Resource identity, custom mappings/equality, arbitrary Python objects, plugin/session cache, resource mutation or arbitrary inherited APIs. Python typing.cast does not constrain expression results; Go Value likewise permits any ordinary JSON shape.
- Ordinary mapping equality and location project equality keep Python bool-number recursive compatibility but compare mathematical JSON decimals exactly rather than binary-float JSON rounding. Ordinary truthiness also uses exact mantissa zero; for example 1e-9999 stays truthy rather than underflowing to Python float zero. JMESPath scalar boolean-number equality is distinct, container/contains equality follows the selected Python reference, and JMESPath numeric zero stays truthy.
- The engine is a licensed adapted source fork of official go-jmespath v0.4.0 with full grammar and all 26 standard functions. Independently selected jmespath.py 1.0.1 is a comparison reference satisfying SDK jmespath>=0.9.0, not an installed-version SDK pin or a claim that every version in that range has identical runtime behavior. Custom Python functions/classes and nonordinary JSON values are outside this API representation.
- JMESPath equality/order/min/max/sort/by-key preserve exact decimals, including large integers and arbitrary exponent text. Exact abs/ceil/floor and integral sum differ from Python float spelling/rounding; nonintegral sum/avg/floating to_number use finite IEEE-754 conversion and return errors on nonfinite results. Integer arithmetic needing more than 1048576 coefficient digits errors instead of allocating unbounded memory. Numeric ordering never rounds or expands exponent-sized coefficients.
- JMESPath object keys/values/object projections/JSON serialization use deterministic lexical key order, replacing Python dictionary insertion order for expression evaluation. Raw cloud filter objects retain original key order and duplicate last-value at first insertion position. Original nested wire JSON order is retained for identifier container representation; normalized top-level Volume descriptor order follows source MRO.
- Response aliases and duplicate exact response keys use textual last-consumed-wins. Python JSON dictionary duplicate collapse preserves first insertion position before Resource alias consumption, so duplicates interleaved with distinct aliases can produce a different value. This is an explicit ambiguous-wire Go policy, not an assertion of every possible duplicate-key Python response equivalence.
- Volume size uses source int descriptor behavior: bool remains bool, JSON integers are arbitrary precision, finite float JSON truncates its actual float64 value, decimal digit strings convert, signed/padded/nondigit strings and nonnumeric containers become zero, and digit-only nondecimal strings fail. The volume descriptor uses audited Unicode16 tables and does not emulate CPython configurable decimal string digit limits. JMESPath numeric-string digits and identifier printability follow Go Unicode tables; ordinary UTF-8/JSON parser and byte syntax offsets differ from arbitrary Python Unicode objects.
- Computed location never trusts HTTP location: Connection retains known selected cloud/region/auth name/domain facts and the provider recorded native token project scope; row project/zone are raw JSON values with foreign-project names cleared. Direct ServiceClient calls and FromProvider manual/custom auth results cannot reconstruct absent cloud/configuration facts and leave them null unless explicit owned options supply them. Recorded scope does not force authentication refresh; native HTTP reauthentication remains live.
- Native clouds.Parse discards configured project-domain metadata when selecting project ID scope and collapses absent versus empty configuration strings. Go cannot reconstruct those facts from returned AuthOptions or token names; WithCloudLocation/WithVolumeSearchLocation are explicit complete owned overrides. This configuration parser representation boundary is independent from the direct helper body control flow.
- The library owns concrete option callbacks/defaults rather than requiring caller builders. Direct calls capture source facts/header snapshot before original callbacks; Connection applies originals once before cached Cinder selection, then direct delegation snapshots the resulting source. Retained config pointers, callback-slice slot edits and ordinary MoreHeaders edits cannot change prepared owned options. Provider authentication stays live; source fact mutation/cancellation is terminal at checked boundaries.
- Go retains only actually admitted response Body/Header/StatusCode in independent Pages/Observed. Accepted read/Close/schema/source/context errors keep that physical proof without SDK replay; rejected native HTTP/transport failures retain their own native error and never borrow an older accepted page. Safe same-origin/same escaped collection continuation and cycle checks intentionally reject unsafe routes instead of following Python session pagination beyond those guards. Empty arrays terminate before unused continuation links are inspected.
- Go errors are OperationError with actual operation/resource and original causes; local consumed filter/selection errors wrap ErrInvalidOption, ambiguity wraps ErrAmbiguous, and no fabricated HTTP/NotFound evidence is attached. Python deprecation warnings and diagnostic log messages are not reproduced. Concurrent mutation of caller mutable source/config/model data is outside the race-safe contract; independent-result ownership does not claim such mutations are safe.
- Standard function arity and types are validated for every variadic argument, so merge requires all arguments to be objects; selected Python1.0.1 can accept some iterable key/value pairs through dict.update. Standard grammar rejects repeated slice bounds without intervening colons, omitted function commas and trailing commas that the selected Python parser permissively accepts. These stricter malformed-input boundaries are declared rather than falsely reported as matching every Python parser spelling. All valid grammar branches and26 standard function names remain provided.
- Location timing is explicit: Connection defaults snapshot recorded current scope after original option callbacks and before service selection; the owned operation Location is not rewritten by a later native reauthentication scope change. A direct ServiceClient with no Location override reads recorded scope when each row is normalized. Python current_project_id may refresh session authentication during Resource location construction; Go does not add such location-triggered I/O.

## Usage examples

Examples use the surrounding guide's service object and context unless they declare a complete program. Python examples describe the pinned comparison API.

```go
package example

import (
    "context"
    "encoding/json"
    "fmt"

    sdk "github.com/JSYoo5B/go-openstacksdk"
    "github.com/JSYoo5B/go-openstacksdk/blockstorage"
)

func Search(ctx context.Context, conn *sdk.Connection) error {
    result, err := conn.SearchVolumes(ctx,
        blockstorage.SearchVolumesRequest{NameOrID: "data*"},
        blockstorage.WithVolumeSearchFilters(json.RawMessage(
            `{"metadata":{"owner":"worker"},"is_bootable":false}`)))
    if err != nil { return err }
    fmt.Println(string(result.Value), len(result.Volumes), len(result.Pages))

    ids, err := conn.SearchVolumes(ctx, blockstorage.SearchVolumesRequest{},
        blockstorage.WithVolumeSearchExpression("[?size >= `10`].id"))
    if err != nil { return err }
    fmt.Println(string(ids.Value))

    volume, err := conn.GetVolume(ctx,
        blockstorage.GetVolumeRequest{NameOrID: "data"})
    if err != nil { return err }
    if volume.Value == nil { return nil }
    fmt.Println(string(volume.Value))
    return nil
}
```
