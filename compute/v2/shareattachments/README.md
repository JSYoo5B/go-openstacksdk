# Nova server share attachments

SDK 소유 concrete 옵션으로 server 범위의 share mapping Create/Get/List/Delete를 제공합니다. `compute.ShareAttachments`로 접근하며 직접 client를 사용할 때는 `shareattachments.New(client)`를 사용합니다.

[Python·Go 사용 예제와 정확한 범위](../share-attachments-python.md)에 기본값, microversion 2.97, 서버 권한과 실제 응답 보존, 독립 실행 예제를 정리했습니다.
