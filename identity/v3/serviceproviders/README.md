# Service providers

Package serviceproviders implements the pinned openstacksdk identity v3 service provider proxy calls over Keystone OS-FEDERATION/service_providers, a route Gophercloud v2.15.0 does not bind.

Run `go doc ./identity/v3/serviceproviders` for the API. Python openstacksdk mappings, contracts and differences are recorded in the review ledger, `api/sdk_reviews.json`.
