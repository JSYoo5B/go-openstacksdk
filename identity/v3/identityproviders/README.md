# Identity providers

Package identityproviders implements the pinned openstacksdk identity v3 identity provider proxy calls over Keystone OS-FEDERATION/identity_providers, a route Gophercloud v2.15.0 does not bind.

Run `go doc ./identity/v3/identityproviders` for the API. Python openstacksdk mappings, contracts and differences are recorded in the review ledger, `api/sdk_reviews.json`.
