# Module and package names

The Go module is `github.com/JSYoo5B/go-openstacksdk`. The root package name is `openstack`; examples may alias it as `sdk`. Service packages expose higher-level services, and versioned leaf packages expose concrete API operations.

Project naming does not imply affiliation with OpenStack, OpenInfra Foundation, or Gophercloud. See [licensing and attribution](licensing.md).
