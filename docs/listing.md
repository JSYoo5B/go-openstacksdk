# Listing

This guide describes the public Go APIs and their contracts against the pinned Gophercloud and Python openstacksdk sources. Support decisions apply to each operation below.

See the [support ledger](sdk-support-ledger.md) for status definitions and shared limitations.

Python/Go differences:

- Go exposes these local controls through the common Collection or fixed-parent scope; existing native typed List option signatures remain unchanged. Zero means unlimited and negative values fail lazily before HTTP.
- The native path does not infer a wire limit from max_items and stops exactly at the raw row cap. Native whole-page extraction or IsEmpty may still reject unused trailing rows; continuation retains the native pager and SDK cycle policy.
- servers.API.ListCloudRecords is the Python Proxy.servers counterpart and returns owned ServerFindRecord snapshots; the native API.All/List iterators remain the Gophercloud-shaped alternative covered by the consumption controls above.
- The Python control keyword arguments paginated, max_items, microversion and headers are typed RecordFindOption values; raw control, constructor and positional keys (including details, all_projects and base_path, which raise TypeError in Python) and the deprecated Proxy._list jmespath_filters (Python applies jmespath.search to the lazy generator) fail before HTTP. The cloud SearchServers expression filter is the supported JMESPath path.
- A typed all-projects option combined with a raw all_tenants key fails before HTTP instead of letting the typed value win, following the find_server option-ownership policy.
- Continuation links that change the fixed origin, collection path or caller filters are rejected with the actual page receipt instead of being followed, as for find_server; exact relative /v2.1/servers[/detail] aliases are accepted.
- Go accepts final 200..399 list representations and rejects informational statuses with actual proof, the bounded status policy shared with find_server.

Unresolved boundaries:

- Python returns mutable Server Resources with session/cache/dirty state; that runtime is the shared SDK-R1/C1/S1 boundary of docs/sdk-support-ledger.md and is not reproduced by the owned ServerFindRecord snapshots.
- Python forwards dynamic non-integer limit/max_items values; the Go limit and cap controls are nonnegative integers (shared dynamic max_items/limit type boundary).

	"context"
	"fmt"

	sdk "github.com/JSYoo5B/go-openstacksdk"
	"github.com/JSYoo5B/go-openstacksdk/resource"
)

func ListMembers(ctx context.Context, conn *sdk.Connection, poolID string) error {
	service, err := conn.LoadBalancer(ctx)
	if err != nil {
		return err
	}
	scope, err := service.Pools.Members(ctx, resource.ID(poolID))
	if err != nil {
		return err
	}
	for member, err := range scope.List(ctx,
		resource.WithMaxItems(10),
		resource.WithPaginated(false),
		resource.WithStatus("ACTIVE"),
	) {
		if err != nil {
			return err
		}
		fmt.Println(member.ID, member.Name, member.ProvisioningStatus)
	}
	return nil
}

package examples

import (
    "context"

    networkv2 "github.com/JSYoo5B/go-openstacksdk/network/v2"
    "github.com/JSYoo5B/go-openstacksdk/resource"
)

func ListLocalMatches(ctx context.Context, service *networkv2.Service) error {
    policies, err := service.QoSPolicies.Resources.All(ctx,
        resource.WithBodyFilter("rules", []map[string]any{}),
        resource.WithMaxItems(100))
    if err != nil { return err }
    groups, err := service.SecurityAddressGroups.Resources.All(ctx,
        resource.WithBodyFilters(map[string]any{
            "addresses": []string{"192.0.2.0/24"},
        }), resource.WithPaginated(false))
    if err != nil { return err }
    _, _ = policies, groups
    return nil
}

func ListSubnetMatches(ctx context.Context, service *networkv2.Service) error {
    for value, err := range service.Networks.Resources.List(ctx,
        resource.WithBodyFilter("subnet_ids", []string{"subnet-a", "subnet-b"}),
        resource.WithStatus("ACTIVE")) {
        if err != nil { return err }
        _ = value
    }
    _, err := service.SubnetPools.Resources.All(ctx,
        resource.WithBodyFilter("prefixes", []string{"192.0.2.0/24"}),
        resource.WithMaxItems(100))
    return err
}

## Explicit native Body filters

`resource.WithBodyFilter` and `WithBodyFilters` compare explicitly supported raw response fields locally. QoS policies expose rules, address groups expose addresses, subnet pools expose prefixes, and networks expose subnets. Network also accepts subnet_ids as an alias, rejecting both aliases together. Options snapshot JSON and compare whole arrays; nil and empty arrays differ. Raw caps apply before local filtering, and whole-page native decoding can still fail beyond a cap. These options belong to Resources.List/All, not native typed List or FindIdentity.
